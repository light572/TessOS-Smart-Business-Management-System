# TessOS

**Smart Business Management System**

TessOS is a mobile-friendly business management platform being developed for **Tess Mama Enterprise** and designed to grow into a reusable system for small businesses.

## Current version

### Foundation
- Flask backend
- SQLite database
- Business and user records
- Product inventory foundation
- Customer and supplier tables
- Sales and sale-item tables
- Expense table
- Owner login
- Responsive dashboard
- Low-stock alerts
- Stock valuation
- Recent sales area
